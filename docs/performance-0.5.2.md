# Zex 0.5.2 加载性能与取消验证

2026-10-30，Windows 11 x64、Qt 6.8.3，单台 3840×2160 显示器、系统缩放 200%。使用同一台机器和预热后的磁盘缓存。时间从原生启动器入口计至文件就绪且窗口可见，不包含入口前的进程创建时间，不代表其他机器的冷启动表现。

## 本次改动

文件读取、编码解析、文档分配和填充均在后台完成；完整文档准备好后才替换当前内容。载入超过 120 ms 时显示阶段、进度条和取消按钮。取消保留标签及待恢复的位置，可以重试；取消重新载入还保留原文档、阅读位置、选区、折叠、搜索结果和已应用的编码。关闭加载中的标签会请求停止后台工作。过期任务不能覆盖新请求。

文档在后台按完整大小预分配，再分块填充，避免反复扩容。通过 Scintilla 的等宽字体检测加速纯 ASCII 文本的字宽计算；正常字体、中文和表情继续使用原有排版方法，不截断内容、不插入换行、不修改源文件。

## 本机结果

| 场景 | 0.5.1 就绪时间 | 0.5.2 就绪时间 | 0.5.2 加载期间最大界面间隔 |
| --- | ---: | ---: | ---: |
| 1 MiB ASCII 单行 | 1110 ms | 406 ms | 检测到窗口可见时已经完成 |
| 10 MiB 日志 | 453 ms | 453 ms | 16 ms |
| 100 MiB 日志 | 1000 ms | 984 ms | 19 ms |
| 240 MiB 日志 | 1860 ms | 1766 ms | 17 ms |

大日志中的不存在文本搜索依然完成，文件就绪后最大界面间隔为 26～28 ms。小文件单标签三次启动中位数为 406 ms；恢复 100 个标签为 500 ms，且始终只载入活动文件。0.5.1 对应中位数为 406 ms 和 485 ms；差值小于一次 30 ms 诊断轮询周期，不能据此判断微小启动性能变化。

取消测试使用 240 MiB 文件，分别在解析阶段（进度 40%）和准备阶段（进度 80%）点击实际取消按钮，均成功返回可重试状态。按钮处理耗时小于 1 ms；这仅指取消请求的界面处理，后台在下一次检查点退出，不能理解为文件句柄、缓冲区和后台任务在零毫秒内全部释放。读取/准备按 2 MiB 分块，文本检查按 64 Ki 字符分块检测取消。

## 验证范围

- 36 项 Qt 测试：等宽和非等宽字体的字符位置对照、中文/表情/组合字符、跨块 UTF-8 完整性、只读性、取消与重试、关闭正在加载的标签、保留原文档和编码，以及既有功能回归。
- 21 个独立性能/显示场景：100%～400% 有效缩放、10/100/240 MiB 日志、ASCII 与混合 Unicode 长行、两种取消阶段、超限文件、单标签与 100 标签恢复。
- 23 个便携包场景及原生单实例测试：从中文目录、不同工作目录和纯系统 PATH 启动，验证主题、搜索、编码及会话恢复。EXE 属性核对为 sixunited / sclliang / 0.5.2.0 / English (United States)。

## 剩余限制

本次快速字宽计算主要适用于等宽字体的 ASCII 文本。约 704 KiB 的中文与表情混合单行（`中文🙂 ` 重复 65,536 次）就绪时间为 875 ms，首次排版仍观察到约 449 ms 的界面间隔。极长混合文本、非等宽字体和自动换行仍可能短暂停顿；最终排版不在可取消的后台准备阶段中。阻塞中的文件系统调用也要等操作系统返回后才能检查取消。

界面间隔来自 16 ms 定时器采样，加载指标从诊断检测到窗口可见后统计，存在轮询边界误差，不是帧率或响应时间保证。当前文件上限仍为 256 MiB。实体混合 DPI 多屏热插拔及 Windows 10 实机尚未补测。

