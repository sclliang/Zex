Zex 0.8.0 — 文件与代码阅读器
sixunited · sclliang

使用方法
完整解压发布包，双击 Zex.exe。请保留旁边的 bin 文件夹。
通过“打开文件”、Ctrl+O、拖放或命令行参数打开文件。
可一次打开多个文件；拖动标签排序，鼠标中键或 Ctrl+W 关闭。
再次运行 Zex 或从资源管理器打开文件时，会交给已有窗口；重复文件直接切换到原标签。
最小化的窗口会恢复。批量打开时先显示最后一个文件，其余新标签按需读取。

本版为只读查看器，支持选择、复制，不会修改或保存原文件。
支持常见代码、配置、日志和纯文本文件，自动识别语言并高亮。

搜索与结果列表
Ctrl+F 打开搜索栏：Aa 区分大小写，ab 全字匹配，.* 开启正则表达式。
搜索栏悬浮在当前阅读区的右上方，不挤压正文；分屏较窄时自动改为两行。
正则支持 Unicode，例如 \d+ 匹配数字、^ERROR.* 匹配以 ERROR 开头的行。
默认按普通文字搜索；两种模式均支持到达末尾后循环查找。
先选择一段文本，再点击“仅搜索当前选区”图标，即可仅搜索这段固定范围；结果跳转不会改变范围。
选区模式下，正则的行首、行尾和前后文以所选文本为边界；切换文件或分屏会退出选区模式。
点击列表按钮显示匹配行与列号，点击条目跳转；拖动列表上边缘可调整高度。
最多高亮和列出 10,000 个结果；F3 / Shift+F3 仍可查找后面的匹配。
点击方形停止按钮取消搜索，保留已经找到的结果；按 Enter 重新开始。
正则在后台执行，超过约 3 秒或复杂度限制时显示原因；可简化表达式或缩小选区重试。
正则文本输入最多 4,096 个字符；不支持会拆开 UTF-8 字符的 \C。
日志跟随追加内容后，正则结果失效，按 Enter 重新搜索；普通文字搜索仍会更新。

行书签
点击行号右侧的书签栏，或按 Ctrl+F2，为当前行添加 / 取消书签。
F2 跳到下一个书签，Shift+F2 跳到上一个，到达边界会循环。
“查看 → 书签”可清除当前文件的全部书签，每个文件最多 1,000 个。
书签随打开的标签保存，下次启动自动恢复；不会写入原文件。
书签按行号保存，外部插入或删除行后不追踪原文，超出文件长度的书签会移除。
关闭标签会移除它的会话记录和书签。

左右分屏
Ctrl+\，或点击标签栏最右侧的分屏按钮，打开 / 关闭右侧阅读区。
初次分屏显示当前文件；两侧可查看同一文件的不同位置，也可选择不同文件。
先点击某一侧，再切换标签、Ctrl+P 或打开文件，操作会作用于这一侧。
两侧标题栏的叠页按钮可以直接为该侧选择文件；强调色下划线表示当前侧。
搜索、编码切换、跳转和日志跟随作用于当前侧，阅读位置与编码独立；同一文件的书签同步。
拖动中间分隔线调整宽度；右侧标题栏的关闭按钮收起分屏，保留左侧和全部标签。
关闭右侧正在显示的文件标签时会收起分屏；固定标签依然受关闭保护。
下次启动恢复两侧文件、阅读位置、当前侧和宽度比例；只加载两侧可见文件，其余标签继续按需加载。

快速切换文件与整理标签
按 Ctrl+P，或点击标题栏中间的搜索框，搜索已打开和最近使用的文件。
支持文件名、路径和模糊匹配；可用空格分开目录与文件名，例如 client main。
列表显示文件图标、完整路径和已打开 / 已固定 / 最近使用状态，方便区分同名文件。
↑ / ↓ 选择，PageUp / PageDown 翻页，Enter 打开，Esc 取消；也可双击条目。
标签栏的下箭头打开全部标签列表，按当前标签顺序显示，并支持筛选。
快速切换最多保留 50 个最近使用的文件；“文件 → 最近打开”菜单显示最近 12 个。
筛选只匹配已有的文件名与路径，不扫描目录，也不会提前载入休眠标签。
右键标签可固定或取消固定。固定标签显示图钉、排列在前面，并随会话保存。
固定标签可在固定组内拖动；普通标签也可自由排序。拖动不会将两组混在一起。
Ctrl+W、中键、关闭其他 / 右侧 / 全部标签都会保留固定标签。关闭固定标签需先取消固定。

日志实时跟随
打开文件后，点击路径栏“跟随文件”，或在“查看”菜单中开启。
开启时重新读取一次当前文件并跳到底部，随后在后台分批读取新增内容。
向上滚动会暂停跟随，保持当前内容与阅读位置；滚动回到底部或点击“回到底部”继续。
暂停前已经开始的一小批追加可能完成，但不会将视图拉回底部。
切换到其他标签时停止轮询，切换回来继续；关闭标签或“停止跟随”会取消后台任务。
文件被清空或替换时从新内容开始；暂时不存在或无法读取时保留已显示内容并等待恢复。
暂停阅读时不会用替换后的文件覆盖当前内容，恢复跟随后才载入新内容。
支持 UTF-8、GB18030、GBK、UTF-16 LE/BE 和 UTF-32 LE/BE；未写完的字符等待下一次追加。
自动编码在首次读取时确定；编码变化、无效字符或超过 256 MiB 时可能停止跟随，并显示原因。
重新载入或手动切换编码会停止跟随，需要时可再次开启。
跟随开关不跨重启保存，避免启动时自动监视日志；原有阅读位置和固定标签照常恢复。

文件加载
较大的文件会显示加载阶段、进度条和“取消”按钮；小文件直接显示，避免进度条闪烁。
加载时可以切换或关闭标签。取消后标签和待恢复的阅读位置仍保留，可点击“重新加载”继续。
重新载入已有文件时，原内容保持可阅读；取消后保留原内容、位置、选区和已应用的编码。
关闭加载中的标签会取消其后台任务。
等宽字体下的 ASCII 超长行显示已加速；大量中文、表情或非等宽字体仍按正常方式排版。

高缩放和多显示器
窗口会根据当前屏幕可用区域调整，显示器断开或缩放变化后可重新定位。
设置窗口较小时可以滚动查看内容，底部的应用、保存和关闭按钮保持可见。
大文件搜索会分批扫描；更换关键词或关闭搜索可以取消正在进行的扫描。

Windows 集成
通过“查看 → Windows 集成…”开启文件右键菜单，并勾选可用 Zex 打开的文件类型，再点击“保存”。
Windows 11 的“使用 Zex 打开”位于右键菜单的“显示更多选项”中。
“保存并设置默认打开方式…”会打开 Windows 默认应用设置，在其中选择 Zex 作为所需类型的默认程序。
Windows 10 或较早版本若没有直接定位到 Zex，可在默认应用中按文件类型选择。
设置仅对当前用户生效，不需要管理员权限；保存注册不会直接替换现有默认程序。
“撤销全部集成”移除 Zex 的右键菜单和打开方式注册；若曾手动设为默认，请在 Windows 默认应用中改选其他程序。
移动发布包后，在新位置运行 Zex 并重新保存集成设置，即可更新注册路径。

手动选择编码
点击底部状态栏的编码，或选择“文件 → 以编码重新打开”。
支持自动识别、UTF-8、GB18030 / GBK、GBK、UTF-16 LE / BE、UTF-32 LE / BE。
无 BOM 的 UTF-16 / UTF-32 文件可通过对应的手动选项打开。
只会以所选编码重新读取，不会转换或保存原文件。错误或不完整的字节序列会提示失败，可随时改回自动识别或其他编码。
每个标签单独记住编码，重新载入和下次启动会继续使用；切换时尽量保留原来的阅读位置。

外观设置
通过“查看 → 外观设置…”或 Ctrl+, 打开设置窗口。
“界面主题”提供石墨（中性深色默认）、午夜蓝、北境、紫夜、纸白、暖砂六套配色，包含四套深色和两套浅色。
选择时可在设置窗口预览，点击“应用”或“确定”后同步更新窗口与代码颜色，并记住选择。
下次启动直接使用保存的主题。切换主题会保留标签、阅读位置、搜索结果和折叠状态。
可选择字体、8–32 pt 字号、常规/粗体/斜体/粗斜体、注释斜体和行间留白。
默认优先使用 Cascadia Mono，其次 Consolas；字号 11 pt、行间留白 3、注释不倾斜。
升级时仅将完全未改动的旧默认字体组合更新为新默认，自定义字体设置会保留。
下方实时预览；点击“应用”或“确定”后生效并保存，重启后继续使用。
“取消”放弃尚未应用的改动；“恢复默认”先重置预览，应用后才生效。
字体调整对全部标签及以后打开的文件有效，保留当前选区和搜索结果。

文件图标提供 Material 彩色、Seti 彩色、Seti 单色三套内置预设。
按文件名和扩展名匹配，标签、路径栏和最近文件同步更新。
例如 CMakeLists.txt、package.json 有专属图标；未知格式使用通用文件图标。
图标完全离线，不需要下载或安装字体。
工具栏另使用 Codicons 矢量图标，按当前显示缩放绘制。

文件被外部程序修改后，路径栏会显示“重新载入”。

自动识别 UTF-8、带 BOM 的 UTF-16/UTF-32，以及 GB18030/GBK；其他情况可手动选择编码。
最大支持 256 MB 文件。超过 8 MB 或单行超过 20,000 字符时启用大文件模式，关闭高亮。
程序记住窗口、字体样式、图标预设、换行设置及最近文件。

自动恢复阅读
下次启动时自动恢复上次打开的文件、标签顺序、当前标签和各文件的阅读位置。
阅读位置包含页面滚动位置、横向滚动、光标与选区；自动换行时也会恢复到相应位置。
启动时只载入当前可见文件（分屏时最多两个视图），其余标签切换过去才读取。
通过命令行打开文件时，会保留原会话，并优先显示指定文件；已有文件不会重复开标签。
文件暂时不存在时会保留标签，显示“重试打开”；文件变短时会调整到有效行列。
关闭的标签不会在下次启动时恢复；取消所有固定并关闭全部标签后，下次启动显示欢迎页。
会话在阅读过程中合并保存，正常关闭时再保存一次。
会话位置保存在 %LOCALAPPDATA%\sixunited\Zex\session.json，不复制文件内容。

运行要求：Windows 10/11 x64。Qt 和 MSVC 运行库已随包提供。
公司、作者及版本可在 Zex.exe 的“属性 → 详细信息”查看。
开源组件声明与许可证：bin/licenses。
